Copying Event Data from the Editors Workspace

To copy MIDI events as tab-delimited text from your project (GarageBand):

  1. Open the Editor: Select a MIDI region and choose View > Show Editors (or press E).
  2. Click either the Piano Roll or Score tab.
  3. Select all events: Edit > Select All (or Command–A).
  4. Copy to clipboard: Edit > Copy (or Command–C).
  5. Paste into a text document or this tool.

Event List Column Specifications

ColumnParameterFormatDescriptionValue Range
1 Position Bars . Beats . Divisions . Ticks Point in time where the event starts Bars: 1–9999
Beats: 1–4
Divisions: 1–4
Ticks: 1–240 (960 PPQ)
2 Status Alphanumeric String Event type Note#EvE, SysEx, Control, etc.
3 Ch Integer MIDI channel 1–16
4 Num Note Name / Pitch Register MIDI note number (pitch) C-2 – G8 (MIDI 0–127, Middle C = C3 = 60)
5 Val Integer Velocity 1–127 (0 = Note Off)
6 Length/Info Bars . Beats . Divisions . Ticks Duration of the note Bars: 0–9999
Beats: 0–3
Divisions: 0–3
Ticks: 0–239

Based on Apple Logic Pro documentation. Ticks are relative to the 960 PPQ internal clock.
